# Minescape website

This build-free site is the source for the Minescape GitHub Pages site.

Configure GitHub Pages to deploy from the `main` branch and the `/docs` folder. The public URL will be:

`https://cbulock.github.io/minescape/`

For a local preview, serve this directory with any static HTTP server. For example:

```powershell
python -m http.server 4173 --directory docs
```
